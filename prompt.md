# Prompt: Генератор карт звездного неба

## Описание проекта
Создание бесплатного веб-аналога генератора карт звездного неба. Сайт позволяет пользователю ввести местоположение, дату и время, настроить отображение элементов неба и сгенерировать персонализированную карту в формате 4K PNG.

## Используемые библиотеки и референсы

### Основные библиотеки:
1. **[ofrohn/d3-celestial](https://github.com/ofrohn/d3-celestial)** — интерактивная карта неба на D3.js
   - Основная библиотека для рендеринга карты звездного неба
   - Поддержка созвездий, планет, проекций

2. **[ogun/starmap](https://github.com/ogun/starmap)** — программа для отображения положения звёзд по дате и координатам
   - Альтернативный источник алгоритмов позиционирования

3. **[stellarium/stellarium](https://github.com/stellarium/stellarium)** — полноценный планетарий с открытым исходным кодом
   - Референс для точности астрономических данных
   - Источник каталогов звёзд и созвездий

4. **[thelazyone/starmap_js](https://github.com/thelazyone/starmap_js)** — встраиваемая JS-библиотека для карт звёзд
   - Легковесная альтернатива для клиентского рендеринга

## Функционал сайта

### 1. Доступность
- Любой пользователь может зайти на сайт без регистрации

### 2. Ввод местоположения
- Поле ввода города (с автодополнением)
- Опционально: страна или регион
- Привязка к географическим координатам (широта, долгота)
- Использование geocoding API (например, OpenStreetMap Nominatim)

### 3. Ввод даты и времени
- Date picker для выбора даты
- Time picker для выбора времени
- Часовой пояс определяется автоматически по городу или выбирается вручную

### 4. Настройки отображения (чекбоксы)
- [ ] **Линии созвездий** — отображать/скрыть соединительные линии созвездий
- [ ] **Подписи созвездий** — отображать/скрыть названия созвездий
- [ ] **Млечный путь** — отображать/скрыть полосу Млечного пути

### 5. Поле "Пожелания"
- Текстовое поле свободного ввода
- Ограничение: **250 символов максимум**
- Отображается на финальной карте

### 6. Генерация карты
- Кнопка **"Сгенерировать карту"**
- После нажатия формируется квадратный холст

## Требования к финальному изображению

### Композиция холста:
- **Формат**: Квадратное изображение
- **Разрешение**: 4K (3840×3840 пикселей)
- **Плотность пикселей**: Высокая (300 DPI для печати)
- **Формат файла**: PNG с прозрачностью или белым фоном

### Расположение элементов:
1. **Карта звездного неба (70% площади)**
   - Форма: **Круг** (круглая проекция неба)
   - Расположение: Центр верхней части холста
   - Содержимое согласно настройкам пользователя

2. **Информация о месте**
   - Город, страна/регион (из пункта 2)
   - Расположение: Под картой

3. **Дата и время**
   - Выбранные пользователем дата и время
   - Формат: ДД.ММ.ГГГГ ЧЧ:ММ
   - Расположение: Под информацией о месте

4. **Пожелания**
   - Текст из поля ввода (пункт 5)
   - Расположение: В нижней части холста
   - Стиль: Декоративный шрифт, центрированное выравнивание

## Дизайн сайта

### Референс дизайна:
- **https://in-space.ru/starmap/**
- Минималистичный, современный интерфейс
- Тёмная тема с акцентами (космическая стилистика)
- Плавные анимации и переходы
- Адаптивная вёрстка (mobile-first)

### Цветовая палитра (рекомендации):
- Фон: Тёмно-синий/чёрный (#0a0e29, #1a1f3c)
- Акценты: Золотой, белый, светло-голубой
- Текст: Белый/светло-серый

### UI-элементы:
- Крупные input-поля с иконками
- Стильные чекбоксы с кастомным дизайном
- Кнопка генерации с hover-эффектом
- Прелоадер во время генерации карты
- Предпросмотр перед скачиванием

## Технические требования

### Frontend:
- HTML5, CSS3 (SCSS), JavaScript (ES6+)
- Фреймворк: React.js или Vue.js (на выбор)
- D3.js для рендеринга карты
- Canvas API или WebGL для высококачественного рендеринга
- Библиотека для гекодинга (leaflet + nominatim или аналог)

### Рендеринг изображения:
- Использование html2canvas или canvas напрямую
- Генерация в высоком разрешении (scale factor ×4)
- Экспорт в PNG через download атрибут

### Backend (опционально):
- Node.js/Express или Python/Flask
- API для гекодинга (если нужен серверный proxy)
- Кэширование запросов к астрономическим данным

### Производительность:
- Быстрая загрузка страницы (<3 сек)
- Генерация карты <5 секунд
- Оптимизация для мобильных устройств

## Дополнительные возможности (future enhancements)

- Добавление логотипа/водяного знака
- Выбор цветовой схемы текста
- Сохранение в PDF

## Этапы разработки

1. **Настройка проекта** — инициализация репозитория, установка зависимостей
2. **Вёрстка интерфейса** — создание формы ввода по референсу
3. **Интеграция гекодинга** — получение координат по названию города
4. **Подключение d3-celestial** — базовая карта неба
5. **Реализация настроек** — чекбоксы для слоёв карты
6. **Компоновка холста** — сборка всех элементов в единое изображение
7. **Генерация PNG** — экспорт в 4K качестве
8. **Тестирование и оптимизация** — проверка на разных устройствах
9. **Деплой** — публикация на хостинге (Vercel, Netlify, GitHub Pages)
